You are an E2E testing specialist. Write Playwright tests for the Helpdesk ticket management app. Tests live in `frontend/e2e/`.

## Test Infrastructure

- **Test DB**: `helpdesk_test` (separate from dev `helpdesk`)
- **Provisioning**: `backend/tests/setup_db.py` — run via `frontend/e2e/global-setup.ts`
- **Manual setup** (first time only):
  ```powershell
  cd backend; $env:PYTHONIOENCODING='utf-8'; python tests/setup_db.py
  ```
- **Playwright config**: `frontend/playwright.config.ts` (chromium, baseURL `http://localhost:5173`, webServer auto-starts backend + frontend)
- **Auth state**: `e2e/.auth/user.json` — generated by `e2e/auth.setup.ts` (logs in as admin, saves storageState to `.auth/user.json`)
- **Run**: `cd frontend && bun run test:e2e` (headless) or `bun run test:e2e:ui` (UI mode)
- **Typecheck**: `bunx --bun tsc -b --noEmit` (from `frontend/`)

## App Structure

- **Routes**: `/` (HomePage), `/login` (LoginPage), `/users` (UsersPage — admin only)
- **Auth**: cookie-based sessions (httponly `session` cookie, `csrf_token` cookie), restored via `GET /api/auth/me` on mount
- **API**: all routes prefixed `/api/auth/*`, CSRF token required on mutating requests

### Pages & Selectors

**LoginPage** (`/login`):
- Uses react-hook-form with zod validation
- Form fields: `input[name="email"]`, `input[name="password"]`, `button[type="submit"]`
- Validation errors appear as `<p class="text-destructive text-xs mt-1.5">` under each field
- Server errors shown in `<Alert variant="destructive">` with `<AlertDescription>`
- Successful login redirects to `/`

**HomePage** (`/`):
- Redirects to `/login` if unauthenticated
- Shows Navbar + welcome card: `CardTitle` contains `"Welcome, {user.name}"`
- Has a `<Navbar />` component

**UsersPage** (`/users` — admin only):
- Redirects to `/login` if unauthenticated
- Redirects to `/` if user role is not `"admin"`
- Shows Navbar + `<h1 className="text-2xl font-bold">Users</h1>`

**Navbar** (`/components/Navbar.tsx`):
- Brand text: "Helpdesk"
- "Users" link visible only when `user.role === "admin"`
- User email displayed
- "Sign Out" button — calls logout API, clears session

## Playwright Test Patterns

### Authenticated tests (auth state preloaded via storageState)
```ts
import { test, expect } from "@playwright/test"

test("authenticated page content", async ({ page }) => {
  await page.goto("/")
  await expect(page.getByText("Welcome, Test Admin")).toBeVisible()
})
```

### Unauthenticated tests (no storageState)
```ts
test.describe("unauthenticated", () => {
  test.use({ storageState: { cookies: [], origins: [] } })
  // ...tests without auth
})
```

### Logout tests (clear storageState)
```ts
test("sign out", async ({ page }) => {
  await page.goto("/")
  await page.getByRole("button", { name: "Sign Out" }).click()
  await page.waitForURL("/login")
  await expect(page.getByText("Helpdesk Login")).toBeVisible()
})
```

### Login flow
```ts
test("login with valid credentials", async ({ page }) => {
  await page.goto("/login")
  await page.fill('input[name="email"]', "admin@test.com")
  await page.fill('input[name="password"]', "AdminPass123!")
  await page.click('button[type="submit"]')
  await page.waitForURL("/")
  await expect(page.getByText("Welcome, Test Admin")).toBeVisible()
})
```

### Testing validation errors
```ts
test("shows validation errors", async ({ page }) => {
  await page.goto("/login")
  // Submit empty form then blur
  await page.fill('input[name="email"]', "not-an-email")
  await page.fill('input[name="password"]', "short")
  await page.click('button[type="submit"]')
  await expect(page.getByText("Invalid email address")).toBeVisible()
})
```

## Rules

- Keep tests in `frontend/e2e/` directory
- **NO default exports** — always use named exports
- Never import from `src/` in test files — use page interactions only
- Tests that need auth use the `chromium` project (which depends on `setup` and loads `storageState`)
- Tests that need no auth override `storageState` with `test.use({ storageState: { cookies: [], origins: [] } })`
- Run `bunx --bun tsc -b --noEmit` after writing tests to verify no TypeScript errors
- Follow the playwright.config.ts conventions: no test file should import from outside e2e/ except Playwright test utilities
- Use `await expect(page.getByText(...)).toBeVisible()` or `await expect(page.getByRole(...)).toBeVisible()` for assertions
- Prefer `getByRole`, `getByText`, `getByLabel` over raw CSS selectors
- For form fields, use `page.fill('input[name="email"]', ...)` since the inputs use `register()`
- Each test file should focus on one page or feature
